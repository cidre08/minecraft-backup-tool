# 🟩 マイクラ自動バックアップ作成ツール（スマート起動版）

ブラウザ上で簡単な設定を入力するだけで、マインクラフトのセーブデータを自動で定期バックアップしてくれるツール（Windows用）を生成・ダウンロードできるWebツール＆スクリプトです。

今回の新バージョンでは、**「マイクラの起動と同時にバックアップも自動スタートし、ゲームを閉じれば勝手に終了する」**完全連動型のスマート起動に対応しました！

---

## ✨ 主な特徴・新機能

- **マイクラと完全連動するスマート起動（VBScript連携）**
  - 専用の起動用ファイル（`start_minecraft.vbs`）を使うことで、マイクラの起動と同時にバックアップがタスクバーに最小化状態で常駐し始めます。
  - ゲームを終了すると、バックアップツールも自動的にパッと終了するため、閉じ忘れてバックアップし続ける心配がありません。
- **タスクバーで稼働中が一目で分かる安心設計**
  - 邪魔な黒い画面が大きく開かず、タスクバーにアイコンとして静かに常駐するため、裏でしっかり動いているかをいつでも確認できます。
- **容量を圧迫しない（最新3世代を自動維持）**
  - 指定した時間おきにバックアップを作成しますが、常に**最新の3世代だけ**をキープし、古いものは自動で削除・整理されます。
- **元データを守る安全設計**
  - セーブデータを直接改変・上書きせず、別の保存先フォルダへ「コピー」を作成する仕組みです。
- **あとからの時間変更も簡単**
  - ツールの下部にある専用エリアにいま使っている `backup.bat` をポンとドラッグ＆ドロップするだけで、設定を維持したまま時間だけを変更した新しいファイルが簡単に再作成できます。

---

## 🚀 使い方

1. ブラウザから本ツール（HTML）を開きます。
2. 「公式版Java」または「CurseForge」を選択し、ワールド名や保存先、バックアップの間隔（分）を設定します。
3. **[📦 必要なファイルをまとめて一括ダウンロード]** ボタンを押し、**`backup.bat`** と **`start_minecraft.vbs`** の2つのファイルをダウンロードします。
4. ダウンロードした**2つのファイルを必ず同じフォルダ（デスクトップの専用フォルダなど）に一緒に入れます**。
5. **アイコンを可愛くしたい場合：** `start_minecraft.vbs` を右クリックして「ショートカットの作成」を行い、プロパティからマイクラ等のアイコンに変更すると便利です。
6. 今後はそのファイル（またはショートカット）を起動するだけで、マイクラとバックアップが同時に連動して動き出します！

> **⚠️ 初回起動時のセキュリティ警告について**
> - ファイルを初めて開く際にWindowsから警告が出た場合は、ファイルを右クリックして**「プロパティ」**を開き、一番下にあるセキュリティの**「許可する（またはブロックの解除）」**にチェックを入れて**「OK」**を押すとスムーズに開けるようになります。

---

## 🛟 万が一クラッシュしたときの復旧手順

1. **マイクラを完全に終了する**：ゲームが起動したままだと上書きできないため、必ず閉じます。
2. **元データを安全な場所に退避させる**：トラブル防止のため、壊れてしまった元のワールドフォルダを別の場所へコピー（または移動）して退避させます。
3. **バックアップからワールドフォルダを取り出す**：保存先フォルダを開き、クラッシュする直前の時間が名前に付いているフォルダから、ワールド名のフォルダを丸ごとコピーします。
4. **元の saves フォルダに戻す**：コピーしたワールド名のフォルダを、元の `saves` フォルダに貼り付けて上書きします。
5. **ゲームを起動する**：マイクラを起動してワールドを開けば、バックアップ時点の状態に復活します！

## 💻 パソコンへの影響について（安全性）

- **常駐ソフトやレジストリ書き換えは行いません**
  - 専用のインストール型ソフト等ではなく、ウィンドウを閉じればプログラムは完全に停止します。
- **完全ローカル環境で完結**
  - 外部へのデータ送信やインターネット通信は一切行わず、お使いのパソコン内だけで完結するためプライバシー面も安心です。
