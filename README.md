# 🟩 マイクラ自動バックアップ作成ツール

ブラウザ上で簡単な設定を入力するだけで、マインクラフトのセーブデータを自動で定期バックアップしてくれるWindows用バッチファイル（`.bat`）を生成・ダウンロードできるツールです。

---

## ✨ 主な特徴

- **容量を圧迫しない（最新3世代を自動維持）**
  - バックアップは時間ごとに保存されますが、常に**最新の3世代だけ**をキープし、古いものは自動で削除されます。
- **安心の自動終了＆通知機能**
  - マイクラを終了し、ワールドの更新（セーブ）がなくなってから**1時間（60分）経過すると自動で監視を終了**します。
  - 終了時にはWindowsのポップアップ（メッセージボックス）でお知らせするため、PCのバックグラウンドで無駄に動き続ける心配がありません。
- **元データを守る安全設計**
  - 元のセーブデータを直接上書き・改変するのではなく、別の保存先フォルダへ「コピー」を作成する仕組みです。

---

## 💻 パソコンへの影響について（安全性）

- **常駐ソフトではありません**
  - 専用のインストール型ソフトやWindowsのシステム深部（レジストリ等）を書き換える常駐アプリではありません。バッチファイルのウィンドウを閉じれば、プログラムは完全に停止します。
- **完全に元の状態へ戻せます（アンインストール不要）**
  - 使わなくなったときは、デスクトップにある **`backup.bat`** ファイルと、バックアップが保存されている **`MinecraftBackup` フォルダ**をそのままゴミ箱に捨てるだけで、PCに一切ゴミを残さず綺麗に削除できます。

  - あくまでプレイヤーが自己管理しているローカルのセーブデータフォルダ（`saves`）のコピーを定期作成する補助スクリプト（バッチファイル）です。

## 🚀 使い方

1. ブラウザからツールを開きます。
2. **「ワールドのフォルダ名」**を入力します（例: `New World` など）。
3. **[💾 batファイルとしてダウンロード]** ボタンを押します（通常、「ダウンロード」フォルダに `backup.bat` が保存されます）。
4. ダウンロードしたファイルを**デスクトップに移動**させます。
5. マインクラフトを遊ぶ前に、その `backup.bat` を**ダブルクリックして起動**します！

> **⚠️ 重要な注意点（ウィンドウについて）**
> - バッチファイルを起動すると**黒い画面（コマンドプロンプト）**が開きますが、**マイクラを遊んでいる間はこの画面を開きっぱなしにしておく必要があります。**
> - この画面を途中で「✕」などで閉じてしまうと、バックアップ機能も停止してしまうためご注意ください。
> - マイクラ終了後、1時間ワールドの更新がないと**自動でウィンドウが閉じ、プログラムも終了**します。
